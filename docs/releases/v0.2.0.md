# v0.2.0 — Laravel AI 1.3

Published on **2026-10-26** as [v0.2.0](https://github.com/RedberryProducts/synapse/releases/tag/v0.2.0). These notes describe that release; validation below records the tested candidate.

Synapse now uses Laravel AI 1.3 for agent execution, streaming, recording, and conversation replay. This is a **breaking pre-1.0 upgrade**: existing installations must clear Synapse history and uploaded attachments with their old installation before updating. Read the [upgrade guide](../../UPGRADE.md) before changing dependencies.

## What's changed

- Agent middleware, skills, cache settings, and generation options pass through the SDK's execution pipeline.
- Text, reasoning, and tool results keep their order in the live conversation and after reload. Useful partial output remains visible when a later step fails.
- Usage follows the SDK's input/output terminology. Cache usage is included in input; reasoning is included in output, without double-counting.
- Discovery recognizes skill loaders, wrapped sub-agents and MCP tools, failover provider/model maps, and provider-specific settings.
- Tools that require approval pause without executing. The dashboard explains the pause; approve, deny, and resume controls remain planned in [issue #1](https://github.com/RedberryProducts/synapse/issues/1).

## Fixes and security

- A `Stringable` tool result now produces one tool card containing both its output and timing.
- Paused and failed turns show their recorded usage immediately, including after another message is sent.
- Unavailable agents show their actionable discovery error in the playground, with saved history still readable.
- Existing fixes for long agent names, initial loading, production provider registration, and published migrations after package removal remain covered.
- Optional `laravel/mcp` installations must resolve to **1.1.0 or later**, enforcing the patched 1.x floor for [GHSA-m25c-38v7-94p8](https://github.com/laravel/mcp/security/advisories/GHSA-m25c-38v7-94p8).

## Requirements and upgrade

- PHP 8.3+.
- Laravel 12.62+ or 13.15+ for API compatibility. Deploy a current patched Laravel version; the historical minimums predate framework security fixes.
- Laravel AI `^1.3`.

For a fresh installation of 0.2.0:

```bash
composer require --dev 'redberry/synapse:^0.2'
php artisan synapse:install
```

For an existing installation, follow [UPGRADE.md](../../UPGRADE.md). It covers backups, clearing old Synapse storage before dependency changes, SDK migration, publishing the follow-up migrations, preserving the access gate, and verification. There is no history backfill. Synapse does not clear or migrate the SDK's conversation tables. Host applications do not need an npm build or asset publication.

## Validation and limitations

Candidate `6261a58` passed release validation on **2026-10-26**:

- Pint, PHPStan, and **290 PHP tests / 932 assertions** in eight PHP 8.3/8.4 × Laravel 12/13 × minimum/newer framework combinations.
- **86 browser tests / 353 assertions** on both Laravel majors, using deterministic fake agents.
- Composer validation, TypeScript, production build, and package/test-app dependency audits.
- Real OpenAI `gpt-4.1-mini` smoke tests for all ten callable demo agents, plus the intentionally unavailable agent: chat, conversational/stateless history, tools, skills, structured output, approval pause, failure recovery, delegation, local MCP, reload, usage, and provider identity.
- Real HTTP streaming with output buffering enabled: **8 ms first byte**, **4.8 s total**, with tool input/output arriving separately.

The earlier fresh-install and `--no-dev` deployment rehearsals passed on Laravel 12 and 13. See the [release validation record](https://github.com/RedberryProducts/synapse/blob/v0.3.0/plans/laravel-ai-1.3-migration/RELEASE-VALIDATION.md) for exact versions and evidence.

Structured output remains single-shot. Live qualification covers one OpenAI model and an in-process MCP tool; other providers, failover, reasoning-specific output, provider-hosted tools, remote MCP, and audio/PDF flows were not live-tested. The earlier image test verified transport and persistence but had mixed answer accuracy. Laravel Octane remains unsupported.

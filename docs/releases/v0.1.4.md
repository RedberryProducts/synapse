# v0.1.4 — Laravel AI SDK 0.11 support

Synapse can now be installed in applications already using Laravel AI SDK 0.11, including 0.11.2. Previous Synapse releases rejected that dependency combination during Composer resolution.

## Compatibility

- PHP 8.3+, Laravel 12/13.
- Laravel AI SDK 0.9.x, 0.10.x, or 0.11.x (`^0.9|^0.10|^0.11`).
- Future SDK minor versions require compatibility testing before being added.

## Install or upgrade

For a new installation:

```bash
composer require redberry/synapse:^0.1.4 --dev
php artisan synapse:install
```

For an existing installation whose Composer constraint permits v0.1.4:

```bash
composer update redberry/synapse --with-dependencies
```

If your project pins an older Synapse version, update its constraint first. Upgrading from v0.1.3 requires no migration, configuration change, or asset publishing. Applications on SDK 0.9 or 0.10 can stay on their existing SDK series.

When upgrading from v0.1.2 or earlier, also follow the [v0.1.3 upgrade instructions](https://github.com/RedberryProducts/synapse/blob/v0.1.3/docs/releases/v0.1.3.md).

## Validation

- SDK 0.11.2: 223 PHP tests and static analysis passed on Laravel 12 and 13.
- SDK 0.11.2: all 76 Chromium browser tests passed on Laravel 13.
- Existing SDK 0.10.2: 223 PHP tests passed with the updated test fixtures.
- A fresh Laravel 13.32.0 application with published SDK 0.11.2 installed first accepted the candidate package; installation and migrations succeeded.

Validation used PHP 8.4 and SQLite. Browser agent responses were faked; live provider APIs were not exercised. Existing limitations, including unsupported Laravel Octane and incomplete approval/denial and citation display, remain unchanged.
